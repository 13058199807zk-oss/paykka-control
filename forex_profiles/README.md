# 汇差报价方案（forex_profiles）

本目录存放 **汇差配置整体方案**，供 BOT 指令 `汇差方案列表` / `汇差方案切换 <方案名>` 读取。

## 文件格式

每个方案是一个 `.json` 文件，顶层结构：

```json
{
  "name": "平日报价方案",
  "aliases": ["平日", "工作日", "标准"],
  "note": "说明文字（可选）",
  "updated": "2026-09-30T11:12:20+08:00",
  "config": {
    "USD": {
      "items": [
        {
          "buy_cur": "CNH",
          "configs": [ { "provider": "CC", "type": "BY_DIFF", "value": 0.0025 } ],
          "cost":    { "provider": "CC", "type": "BY_DIFF", "value": 0.0010 }
        }
      ]
    }
  }
}
```

字段说明：

| 字段 | 含义 |
|---|---|
| `name` / `aliases` | 展示名与别名（`汇差方案切换` 时任一命中即可） |
| `config` | **按卖出币种分组**：`卖出币种 → items[]` |
| `items[].buy_cur` | 买入币种（一个卖出币种下的一个币对） |
| `items[].configs[]` | **数据源**列表（可多渠道）；`provider` 为主键 |
| `items[].cost` | **成本底价**（单对象） |
| `type` | `BY_RATIO`（百分比，值填 `0.0016` = 0.16%）／`BY_DIFF`（固定汇差，绝对值） |
| `value` | 数值（按 `type` 解释） |

## 生成方式

最简单：在飞书发 **`汇差查询 快照`**，BOT 会把当前线上全量配置导出成同格式 JSON，
把它的 `config` 段贴进来即可（建议改掉 `name` / `aliases`）。

## ⚠️ 安全约束（BOT 侧硬校验）

`汇差方案切换` 要求**方案里某个卖出币种的买入币种集合，必须与线上完全一致**，
否则直接拒绝提交 —— 因为底层 `edit` 是**整表替换**，方案漏一个币对就等于把它删掉。

## ⚠️ 仓库可见性

`paykka-control` 是 **public** 仓库（含 GitHub Pages「汇率空间一览」）。
本目录内容因此对外可见 —— 请自行判断是否可以接受。
